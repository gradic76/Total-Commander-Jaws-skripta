# Total Commander Jaws skripta

JAWS for Windows scripts that make Total Commander (64-bit) fully usable for blind users.

Status: planning. Nothing to install yet.

- Target: JAWS 2025 and newer, Total Commander 64-bit, any interface language
- Messages: in the Total Commander interface language (English and Croatian first)
- License: MIT
